# TERRA 地球ダイナミクス計画 — 環境変化を3Dモデルに反映する（2026-09-04）

目的: シナリオ(SSP)と年代を動かしたとき、数値やナレーションだけでなく**地球そのものの見た目が科学的に誠実な形で変化する**こと。
前提調査: 一次配布元・ライセンス検証済み（本書末尾のアセット表）。現行実装（e8e0abd時点）の反映状況も棚卸し済み。

## 1. 現状の棚卸し

| チャンネル | 現状 | 判定 |
|---|---|---|
| 海氷 | NSIDC 2025-09マスク × 年代で緯度しきい値収縮 | ✅ 実データ+illustrative明記。維持 |
| 海流速度 | AMOCシナリオ別平均で北大西洋系パーティクル減速 | ✅ 維持 |
| SST | NOAA OISST 2026-08観測テクスチャ | ✅ ただし「現在の観測」固定 |
| **気温レイヤー** | `EVIDENCE_FRAGMENT`の**緯度+サイン波の手続き模様**を`uWarming`で着色 | ❌ フェイク。E1で全廃 |
| **海面レイヤー** | 緯度グラデの手続き色 | ❌ フェイク。E3で置換 |
| 雲・大気・夜景 | スタイル(見せ方)にのみ連動 | ✅ 意図的（気候と誤認させない） |

## 2. 設計原則

1. チャンネルは3種に分類し、**画面上のbasisバッジで常時区別**する: 「評価済みパターン (Assessed pattern)」「観測 (Observed)」「説明用表示 (Illustrative)」
2. **手続き生成の疑似気候模様は全廃**（緯度グラデ・サイン波）。データが無い表現はやらないか、Illustrativeと明記
3. **演出チャンネル禁止則**: 大気の色味・ブルーム強度・雲量をΔTに連動させない（「地球が死んでいく見た目」の編集的演出は誠実性を壊す）。見た目の変化は必ずデータ経由
4. ツール契約(6ツール)のシグネチャは維持。`year`範囲の**下限拡張のみ後方互換として許可**（E2）

## 3. 実装指示（優先度順）

### E1【本丸】気温レイヤーのGWLパターンスケーリング実データ化

- IPCC AR6 Interactive Atlas から **温暖化レベル(GWL) +1.5/+2/+3/+4°C の地上気温変化パターン**（CMIP6アンサンブル平均, vs 1995-2014）を4枚エクスポート → 2048×1024グレースケールPNG化（正規化レンジをJSONに記録）
- シェーダ: `ΔT_global(scenario, year)`（science.tsの既存評価値）から挟む2枚のGWLテクスチャを選び線形補間 → 発散カラーマップ（青白→橙赤、ゼロ点固定）で着色。**北極増幅が年スライダーで視覚的に成長する**のが受け入れ基準
- SSP1-2.6では+3/+4°Cに到達しない → 補間が自然に頭打ちになる（それ自体が誠実な可視化。クランプをUIで隠さない）
- basisバッジ: 「評価済みパターン · IPCC AR6 Atlas (CMIP6)」。凡例（色→°C）を追加
- ナレーション: 「パターンはCMIP6アンサンブル平均をAR6の温暖化レベル手法で補間」の一文を追加

### E2 海氷: 過去観測モーフ + 「観測値」バッジの復権

- NSIDC G02135 v4.0 の **9月extentマスクを1980/1990/2000/2010/2020の5декад分**ラスタライズし、RGBA各チャンネルに詰めた1枚のPNGに（~100KB）
- `year`範囲を **1980–2100に拡張**（スライダー+ツールschemaのminimumを1980へ。既存呼び出しは全て有効=後方互換）
  - 1980–2025: デケードマスク間をシェーダ補間 → **バッジ「観測値」が実際に到達可能になる**（監査新規指摘#5の解消）
  - 2026–2100: 現行のillustrative収縮を継続（バッジ「説明用表示」）
- 過去年では気温レイヤーも:ΔT_global(観測, GISTEMP/HadCRUT評価値の数点表)で同じGWL補間を適用（0.2〜1.3°C帯）

### E3 海面: 海岸ゾーン強調（inundationではない）

- Natural Earth 10m coastline → 距離変換 → **海岸近接グローPNG**（4096×2048, ~300KB）
- 表示: 海岸線に沿う光の帯。強度・幅を `GMSL(scenario, year)` に比例させる（0.0m→ほぼ不可視、1.0m→明瞭）
- ラベル必須: 「海岸ゾーンの強調表示です。浸水域の予測ではありません」（既存の免責文と統一）。basisバッジ「説明用表示 × 評価値連動」

### E4 SST: シナリオ別パターンの追加（時間があれば）

- Atlas/C3SのSST変化パターン（ocean-only alpha）を1枚以上追加し、観測OISST（現在）⇄「+パターン(将来)」を年代で重畳。E1と同じGWL方式でも可
- 観測とパターンの重畳表示には二重バッジ（観測ベース+評価済みパターン）

### E5 遷移の質

- `applyScene`のuniform変化は全て0.4–0.8sのイージング（现在は即時）。年スライダードラッグ中のdraftYearでもGWL補間uniformだけは即時追従させ「地球が手に吸い付く」感を出す（revision確定は既存の250msデバウンスのまま）

## 5. 受け入れ基準（スクショ証跡）

1. 地球全体ビューで SSP5-8.5 の 2030 vs 2100 比較 — **北極増幅の成長が一目で分かる**2枚
2. 同一年2100で SSP1-2.6 vs SSP5-8.5 比較 — シナリオ差が地図上で見える
3. 年1990（E2実装時）で海氷バッジ「観測値」+ 1980⇄2020のエッジ変化
4. 海面レイヤーで GMSL 0.1m vs 0.8m の海岸グロー差 + 「浸水予測ではありません」ラベル
5. 凡例・basisバッジ・DATA_LICENSES.md が揃っている
6. lint/tsc/build クリーン、60fps維持（テクスチャ追加は合計+2MB以内）

## 6. 工数目安

E1: 3–4h（データ変換1.5h+シェーダ1h+凡例/コピー1h）／ E2: 2–3h／ E3: 1.5h／ E4: 2h／ E5: 1h。
縮退順: E4→E2過去拡張→E5 の順に落とす。**E1だけは落とさない**（フェイク模様の全廃が本計画の核）。
