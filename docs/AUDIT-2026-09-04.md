## P0（提出ブロッカー）

1. 【照準ズレ】earth_focus_region('japan') で北米が中央に来る。EarthGlobe.tsx の latLon() とテクスチャ経度写像（makeEarthTexture の x=(lon+180)/360）の座標系不一致が原因。three.js SphereGeometry のUV原点を踏まえ、latLon の theta 符号/オフセット、または globe の初期回転で整合させよ。
   受け入れ基準: Playwright で「日本」「北極」「欧州」を順にクリックし、スクショで各地形が画面中央に来ることを目視確認できる証跡を残す（日本列島が判別できること）。

2. 【海面best値の捏造】science.ts の seaLevel2100.best がレンジ算術平均になっている。IPCC AR6 WGI Table 9.9 の likely range 中央値に修正: SSP1-2.6 → 0.44、SSP2-4.5 → 0.56、SSP5-8.5 → 0.77（low/highは現状維持で正しい）。あわせて temperature の全数値を AR6 Table SPM.1 と突合し、根拠をコミットメッセージに「出典表: 値↔表番号」で明記せよ（SSP1-2.6 near の high=1.8 は 1.7 の疑いあり。必ず原典で確認）。

3. 【海氷「観測値」ラベル】レイヤーバッジを year 依存の動的表示にせよ: year <= 2025 は「観測値 / Observed」、それ以降は「説明用表示 / Illustrative」。terra-metrics やナレーションと矛盾しないこと。
   受け入れ基準: year=2100 で海氷レイヤーのバッジが「説明用表示」になっているスクショ。

## P1

4. 【物語のstomp】物語タイマー実行中に人間またはエージェントが mutate したら、pending の storyTimers を全てキャンセルせよ（mutate と executeCommand の冒頭で storyTimers.current.forEach(clearTimeout) + story:null）。物語ステップ自体も mutate() 経由に統一し、revision 体系の外で setScene しないこと。
   受け入れ基準: 物語再生→0.6秒後にレイヤー変更→5秒待って物語が続行しないことを Playwright で再現確認。

5. 【sea_level物語が未実装】startStory が story 引数を無視して常に arctic シーケンスを再生する。sea_level 用のステップ列（例: global/sea_level/2050 → japan/sea_level/2100 ※地域浸水を主張しない文言）を実装するか、時間がなければツール enum から 'sea_level' を削除して契約と実装を一致させよ。

6. 【遮蔽された流体】WorldLayer が不透明背景の裏で毎フレーム実行されている。二択: (a) terra-stage の背景を透過し、globe の背後に流体が見えるよう合成する（星空との共存を確認）、(b) TERRA では WorldLayer をアンマウントし、README の該当記述を削除。どちらでも「動いていないものを動いていると書かない」を満たすこと。

7. 【AMOCのシナリオ非依存】34–45%減は高排出シナリオ由来の範囲。最低限の修正として、AMOC メトリクスとナレーションに「SSP5-8.5相当の公表レンジに基づく簡略表示」と明記し、SSP1-2.6/SSP2-4.5 選択時は値を出すのをやめるか「このシナリオの評価値は表示していません」と表示する。Weijer et al. 2020 のシナリオ別数値を確認できるなら、シナリオ別レンジに置き換えるのが望ましい。
