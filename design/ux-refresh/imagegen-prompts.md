# Imagegen prompt set

生成方式: OpenAI built-in Imagegen

共通条件: 1536×1024、16:10のデスクトップWebアプリ画面、Factory Makerの実在する製品UIとして描く。広告用の抽象画ではなく、文字・操作・情報階層が読み取れる高精細な画面イメージボード。人の操作はオレンジ、AIの操作は青で区別し、WebMCPによる共同作業、revision、確認、失敗回復が見える。ロゴの過剰使用、架空デバイス枠、読めない疑似文字、チャット中心の構成は避ける。

## A. Shared Canvas

温かいオフホワイトの紙面調。中央の大部分を、企画書・仕様・画面案が育つ共有成果物キャンバスにする。右側には短い変更履歴を置き、人とAIを別の名義と色で表示する。上部には「依頼・方向決定・構築・検証」の控えめな進捗。信頼、共同編集、落ち着きが伝わる編集プロダクト。

## B. Command Studio

濃紺の制作スタジオ。左に短い自然言語の依頼、中央に大きなライブプレビュー、下部に人専用の承認ドック。AIの現在作業、実行ツール、結果を青い運用表示で見せる。速さと集中を感じるが、映画的なSF演出や情報過多にはしない。

## C. Evidence Trail

明るい編集ワークベンチ。画面上部を横切る一本の証拠線に「REQUEST → DIRECTION → BUILD → VERIFIED」を配置し、各節点に担当者、revision、根拠、承認状態を付ける。中央には現在の成果物だけを大きく表示。右に現在のWebMCP操作、READ/WRITE、結果、人の権限境界。下部に差分と取り消し可能な履歴。人とAIが同じ状態を共有していることを一目で理解できる。

## D. Calm Launchpad

余白の多いモバイルファーストの開始画面。最初は「つくりたいサービスを普段の言葉で書く」大きな入力欄と一つの主要ボタンだけを見せる。進行後に次のカードが段階的に開く。安心感、説明不要、44px以上の操作領域、縦一列でも物語が崩れない構成。

## E. Agent Glass

深い紺と半透明パネルの運用コックピット。左に成果物、右に現在のツール一覧とREAD/WRITE、revision、実行結果、Undo、人専用操作を集約する。観測可能性と制御可能性を強く見せる。装飾的なHUDではなく、実際に操作できそうなWeb製品として表現する。
